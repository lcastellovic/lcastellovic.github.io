# lcastellovic.github.io

Sitio web con un menú de aplicaciones y utilidades web. Desde la página principal puedes acceder a la calculadora de interés remunerado y, en el futuro, a nuevas herramientas publicadas con el mismo estilo visual.

## Contenido

- `index.html`: menú principal de aplicaciones.
- `Calculadora_interes_remunerado.html`: calculadora financiera con modo claro/oscuro.

## Uso

Abre `index.html` para navegar por las aplicaciones disponibles.
